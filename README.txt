Wyoming Insulation policy pages

Upload eula.html and privacy.html to the root of a public GitHub repository.
Then open repository Settings > Pages:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)
- Save

After deployment, URLs will be:
https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/eula.html
https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/privacy.html

These are development-stage drafts. Review for accuracy and obtain legal review before commercial release. Update the privacy policy before enabling actual QuickBooks data processing or adding hosting, analytics, storage, or other service providers.
